# Grimoire - Novel Recommendation System

A school project.

Saviour for readers worldwide. Welcome to the humble abode of bibliophiles, where they save time and find what they are looking for in seconds!

Grimoire is the future of literature.


<b>Website</b>

[grimoire-tau-seven.vercel.app](https://grimoire-tau-seven.vercel.app/)

<b>Backend</b>

[grimoire-8w2k.onrender.com](https://grimoire-8w2k.onrender.com/)

## Tech Stack

- Frontend: Astro, Three.js, JavaScript (ES6+)

- Backend: Flask, Python

- Machine Learning / NLP: scikit-learn (TF-IDF Vectorizer, Cosine Similarity), pandas, numpy

## Development Setup

```bash
git clone https://github.com/hiralsinghal/Grimoire.git

# Backend
python3 -m venv venv

# On macOS/Linux:
source venv/bin/activate
# On Windows:
# .\venv\Scripts\activate

pip install -r requirements.txt

python app.py

# Frontend
npm install
npm run dev
```

## Environmental Variables

```bash
PUBLIC_API_URL=http://localhost:5000
```
